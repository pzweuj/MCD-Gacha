# 合规自检清单（参赛）

本项目参加「麦当劳程序员创意开发大赛」，以下为对照活动规则的合规自检项。
脚本化检查：`python scripts/check_compliance.py`（CI 已接入）。

## 内容合规

- [x] 不贬损品牌与产品：全站文案使用正向玩梗（禁用词表与柔化替换对照见
      `src/mcd_gacha/i18n.py`，由 `scripts/check_compliance.py` 全仓扫描）；
- [x] 倡导理性消费：抽卡组合件数上限为 3，文案强调"理性消费，快乐生活"；
- [x] 不宣扬不健康饮食：抽卡结果附带热量信息，鼓励按预算理性点餐；
- [x] 非官方声明：README、分享卡水印、CLI 帮助文本均注明"非官方第三方开源玩具"；
- [x] 不使用官方商标素材：分享卡与网页均为自绘像素风格，不使用金拱门 logo；
- [x] 无违法/敏感内容、无恶意代码、无外部引流链接。

## 信息安全

- [x] 仓库不含真实 Token / 密钥 / 账号凭证；
- [x] 配置示例仅使用环境变量占位符（`mcp-config.example.json` 中 `${MCD_MCP_TOKEN}`）；
- [x] Token 仅存本地配置目录（不进版本库），`.gitignore` 已排除本地配置文件。

## 原创与真实性

- [x] 项目为原创开发（核心算法、文案、素材均为自研）；
- [x] 真实使用麦当劳 MCP 能力（见 `MCP_INTEGRATION.md`：query-meals /
      calculate-price / list-nutrition-foods / now-time-info 等）；
- [x] 真实使用腾讯 WorkBuddy 智能体开发（见 `workbuddy.md`）；
- [x] 不刷 Star、不诱导违规传播：README 中的 Star 引导为常规开源项目表述。

## 禁止行为清单（红线）

- ❌ 刷 Star / 多账号操控（活动规则明令禁止，本项目绝无涉及）；
- ❌ 虚假宣传（如暗示官方背书）；
- ❌ 追踪或倒卖用户数据（本项目不采集任何用户数据，Token 仅本地使用）。
